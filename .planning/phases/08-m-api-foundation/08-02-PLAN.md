**1. Create `src/tools/mplus_rankings.py`** — new module for M+ rankings queries.

The module must contain:

```python
"""
M+ 排行榜查询 — 从 WCL characterRankings 获取 M+ 顶尖玩家数据。

查询模式: characterRankings(difficulty: 10, bracket: N)
缓存策略: mplus_bench:{spec}:{encounter_id}:k{key_level}，TTL 6 小时
稀疏 bracket 回退: 结果 < 3 时尝试相邻 bracket (per D-02)

[PROTOCOL]: 变更时更新此文档，然后检查父级
"""
```

Constants:
- `CACHE_TTL_SECONDS = 6 * 3600` (6h, aligned with raid benchmark TTL)
- `MPLUS_DIFFICULTY = 10`
- `DEFAULT_SAMPLE_SIZE = 5` (per D-04)
- `MIN_RANKINGS_THRESHOLD = 3` (per D-02, below this triggers fallback)

Function `query_mplus_rankings`:
```python
async def query_mplus_rankings(
    client: WCLClient,
    encounter_id: int,
    spec: str,
    key_level: int | None = None,
    sample_size: int = DEFAULT_SAMPLE_SIZE,
) -> tuple[MplusBenchmarkMeta, list[MplusRankingEntry]]:
```

Implementation steps:
1. Parse spec using `_parse_spec` from `timelines.py` pattern (import SPEC_MAPPING from builds.py)
2. Build cache key: `f"mplus_bench:{spec}:{encounter_id}:k{key_level or 'all'}"`
3. Check cache with `cache_get(cache_key, CACHE_TTL_SECONDS)`
4. If cache miss, query WCL `characterRankings` with `difficulty: 10` and optional `bracket: {key_level}`
5. If results < MIN_RANKINGS_THRESHOLD and key_level is not None, try adjacent brackets:
   - First try key_level + 1
   - If still < threshold, try key_level - 1 (minimum bracket = 2)
   - Track `actual_bracket` for disclosure (per D-02)
6. Parse rankings into `MplusRankingEntry` list — extract `report_code` from `ranking["report"]["code"]` and `fight_id` from `ranking["report"]["fightID"]`
7. Compute `MplusBenchmarkMeta` with median_dps, dps_p25, dps_p75 from rankings amounts (use `statistics.median`, `statistics.quantiles`)
8. Cache result with `cache_set`
9. Return `(meta, rankings)`

Per D-03: Do NOT aggregate across key levels. Each bracket query is independent.
