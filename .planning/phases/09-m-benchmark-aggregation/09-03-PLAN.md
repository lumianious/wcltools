**Section: Cross-Player Aggregation**

`_aggregate_segment_data(all_reports: list[dict]) -> list[MplusBenchmarkSegment]`:
- Input: list of report results from `_fetch_report_benchmark_data` (each has `segments` list)
- Group segments across reports by `position`
- For each position, compute medians:
  - `duration_median = statistics.median([seg.duration_sec for seg in segments_at_pos])`
  - For damage_breakdown: group by spell_id across reports. For each spell, median of damage_pct. Keep top TOP_N_DAMAGE_SPELLS by median pct.
  - For cd_casts: group by spell_id across reports. Median of cast_count.
  - For defensive_cds: same as cd_casts but for defensive spells.
  - `interrupt_count_median = statistics.median([seg.interrupt_count for seg in segments_at_pos])`
- Segment type and name: take from first report (all reports share same boss structure)
- Return `list[MplusBenchmarkSegment]` sorted by position
- Handle: some reports may have fewer segments (skip missing positions, require >= 2 reports per position for median)

**Section: Boss Cast-Level Benchmarks**

`_extract_boss_benchmark(client, report_code, fight, source_id, spec) -> dict`:
- For boss segments, extract cast-level data using the rotation.py pattern:
  - Query cast events for the boss fight time range
  - Build spell stats: cast count, CPM, total damage per spell
  - This reuses `_query_segment_cast_events` already built in Plan 02
- Return dict: `{"boss_name": str, "position": int, "cast_stats": [{spell_name, cast_count_median, cpm_median}]}`
- Keep simple for Phase 9 — full cast-by-cast comparison is Phase 10

**Section: Public Pipeline Function**

`async def get_mplus_benchmarks(client: WCLClient, spec: str, encounter_id: int, key_level: int) -> MplusBenchmarkResponse`:
- Cache key: `mplus_bench:{spec}:{encounter_id}:k{key_level}:segments` (per locked decision)
- Steps:
  1. `cache_get(cache_key, CACHE_TTL_SECONDS)` — if hit, return `MplusBenchmarkResponse(**cached)`
  2. `meta, entries = await query_mplus_rankings(client, encounter_id, spec, key_level)`
  3. If no entries, return empty response with meta
  4. Determine boss_names: use encounter info or hardcode known dungeons (Claude's discretion — can be derived from the first report's fight names where encounterID > 0 fights exist, or from a boss name detection heuristic based on fight duration and name patterns)
  5. Fetch all reports in parallel with `asyncio.Semaphore(3)`:
     ```python
     sem = asyncio.Semaphore(3)
     async def _fetch_one(entry):
         async with sem:
             try:
                 return await _fetch_report_benchmark_data(client, entry, spec, boss_names)
             except Exception as exc:
                 logger.warning("Report %s failed: %s", entry.report_code, exc)
                 return None
     results = await asyncio.gather(*[_fetch_one(e) for e in entries])
     valid = [r for r in results if r is not None]
     ```
  6. If `len(valid) < 2`, log warning but proceed with what we have
  7. `segments = _aggregate_segment_data(valid)`
  8. `cd_spacing = _compute_cd_spacing({seg.position: seg.cd_casts for seg in segments})`
  9. Build and cache `MplusBenchmarkResponse(meta=meta, segments=segments, cd_spacing=cd_spacing)`
  10. Return response

```python
@mcp.tool()
async def get_mplus_benchmarks(
    spec: str,
    encounter_id: int,
    key_level: int,
) -> dict:
    """
    Get aggregated M+ benchmark data from top players for a dungeon.

    Returns per-segment benchmarks (damage breakdown, major CD usage,
    defensive patterns, interrupt counts) from top 5 players at the
    specified key level. Segments are boss-bounded (trash between bosses
    is merged). Use this to understand what top players do in each part
    of the dungeon. Cost: ~25-35 WCL points (5 reports x 5-7 queries).

    Args:
        spec: Class specialization slug (e.g., "balance-druid")
        encounter_id: Dungeon encounter ID from get_encounters
        key_level: Mythic+ keystone level to benchmark (e.g., 10, 12)

    Returns:
        Benchmark bundle with segments (damage, CDs, defensives, interrupts)
        and CD spacing pattern across the full dungeon.
    """
    result = await _get_mplus_benchmarks(client, spec, encounter_id, key_level)
    return result.model_dump()
```
