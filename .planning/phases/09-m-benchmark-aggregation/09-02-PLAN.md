**Section 2: `_build_segment_positions(fights, boss_names)` — pure function**
- Input: `fights: list[dict]` (individual segment fights, NOT the aggregate fight), `boss_names: list[str]` (known boss names in this dungeon)
- Sort fights by `startTime`
- Iterate through sorted fights. For each fight:
  - If `fight["name"]` is in `boss_names` (case-insensitive comparison): it's a boss
  - Else: it's trash
- Merge consecutive trash fights into one logical segment (accumulate start/end times)
- Assign positions: 0=first-trash, 1=first-boss, 2=trash-between, 3=second-boss, etc.
- Return `list[dict]` where each dict has: `position: int`, `segment_type: str` ("trash"/"boss"), `name: str`, `start_time: int`, `end_time: int`, `fights: list[dict]` (original fight dicts in this segment)
- Handle edge cases: no trash before first boss (start at position 0 = boss), no trash after last boss

**Section 3: `_extract_segment_damage(entries, top_n=10)` — pure function**
- Input: `entries: list[dict]` from WCL `table.data.entries` (each has `name`, `total`, `id`)
- Compute `total_damage = sum(e["total"] for e in entries)`
- Sort by total descending, take top_n
- Return `list[SegmentDamageBreakdown]` with `spell_name=e["name"], spell_id=e.get("id", 0), total_damage=e["total"], damage_pct=round(e["total"]/total_damage*100, 1)`
- Handle total_damage == 0 (return empty list)

**Section 4: `_extract_segment_cds(events, tracked_spells)` — pure function**
- Input: `events: list[dict]` (cast events), `tracked_spells: dict[int, dict]` from `_build_tracked_spells`
- Filter events where `abilityGameID` is in `tracked_spells`
- Group by spell_id, count casts per spell
- Split by `ability_type`: "dps"/"utility" -> offensive list, "defensive"/"raid_cd" -> defensive list
- Return `(offensive: list[SegmentCDCast], defensive: list[SegmentCDCast])` with `cast_count_median` set to the raw count (median comes later in aggregation)

**Section 5: `_count_segment_interrupts(events)` — pure function**
- Input: `events: list[dict]` from WCL `dataType: Interrupts`
- Return `int` — count of events (each event = one successful interrupt)

**Section 6: `_compute_cd_spacing(segment_cds)` — pure function**
- Input: `segment_cds: dict[int, list[SegmentCDCast]]` mapping position -> CD casts
- Build per-spell presence map: for each spell across all segments, record which positions it appears in
- Return `list[dict]` where each dict: `{"spell_name": str, "spell_id": int, "ability_type": str, "segments": [position_ints]}`

**Section 8: Per-Report Data Extraction (async)**

`_fetch_report_benchmark_data(client, entry: MplusRankingEntry, spec, boss_names) -> dict | None`:
- Steps:
  1. `_query_all_fights(client, entry.report_code)` to get all fights
  2. `_group_fights_by_dungeon(fights)` to get runs
  3. Find the run matching `entry.fight_id`: check if any run's `aggregate_fight["id"] == entry.fight_id`. If none, try time overlap.
  4. `_query_master_data(client, entry.report_code)` for actors
  5. `find_actor_id_ci(actors, entry.name)` for source_id. If None, log warning and return None.
  6. Get segment fights (exclude aggregate fight: `f["id"] != run.aggregate_fight["id"]`)
  7. `_build_segment_positions(segment_fights, boss_names)` for alignment
  8. `tracked = _build_tracked_spells(spec)` for CD filtering
  9. For each segment: query damage table, cast events, interrupt events using segment start_time/end_time. Use the async query helpers.
  10. For each segment: `_extract_segment_damage`, `_extract_segment_cds`, `_count_segment_interrupts`
  11. Return dict: `{"segments": [{position, segment_type, name, duration_sec, damage_breakdown, cd_casts, defensive_cds, interrupt_count}], "source_id": source_id}`
- Wrap individual segment queries in try/except: if a segment query fails, log and skip that segment (degrade gracefully)
