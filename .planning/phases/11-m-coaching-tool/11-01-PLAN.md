    ```python
    class CoachingItem(BaseModel):
        """单条教练建议 — 结构化数据 + 自然语言建议。"""
        category: str = ""          # "damage", "cooldown", "interrupt", "cast", "defensive", "death", "positive"
        spell_name: str = ""
        gap_pct: float = 0.0        # 差距百分比（正 = 玩家低于基准）
        player_value: float = 0.0
        benchmark_value: float = 0.0
        coaching_text: str = ""     # 自然语言建议

    class SegmentCoaching(BaseModel):
        """单个段落的教练输出。"""
        position: int
        segment_type: str = ""      # "trash" or "boss"
        segment_name: str = ""
        items: list[CoachingItem] = Field(default_factory=list)

    class DungeonCoachingSummary(BaseModel):
        """整个副本的教练汇总。"""
        total_damage_flags: int = 0
        total_cd_flags: int = 0
        total_deaths: int = 0
        total_interrupt_flags: int = 0
        top_improvements: list[CoachingItem] = Field(default_factory=list)
        overall_coaching_text: str = ""

    class MplusCoachingResponse(BaseModel):
        """coach_mplus_run 工具返回值 — M+ 副本完整教练报告。"""
        report_code: str
        player_name: str
        spec: str
        dungeon_name: str = ""
        key_level: int = 0
        benchmark_key_level: int = 0
        segment_coaching: list[SegmentCoaching] = Field(default_factory=list)
        death_coaching: list[CoachingItem] = Field(default_factory=list)
        summary: DungeonCoachingSummary = Field(default_factory=DungeonCoachingSummary)
    ```

    **Step 2: Create src/tools/mplus_coaching.py** with these pure functions:

    - `_coach_trash_segment(seg: SegmentComparison) -> SegmentCoaching`: Sort damage_gaps by gap_pct desc, take top 3 flagged. For each, generate NL advice via `_generate_trash_advice`. Also check cd_gaps (flagged) and interrupt_comparison (count_flagged). If no flagged items, add positive CoachingItem with category="positive". Return SegmentCoaching with items capped at 3.

    - `_coach_boss_segment(boss: BossCastComparison) -> SegmentCoaching`: Sort cast_gaps by gap_pct desc (from dict), take top 3 flagged. Also include cd_gaps flagged items. Generate NL via `_generate_boss_advice`. If no flagged items, positive feedback. Cap at 3 items.

    - `_coach_deaths(deaths: list[DeathBreakdown]) -> list[CoachingItem]`: For each death, build coaching_text like "Died at {time}s in {segment_name}. Top damage source: {source}. {defensive_note}." where defensive_note mentions available-but-unused defensives.

    - `_generate_trash_advice(gap: SegmentDamageGap, segment_name: str) -> str`: Return string like "In {segment_name}, your {spell_name} was {player_pct}% of damage vs benchmark {benchmark_pct}%. Focus on using {spell_name} more in AoE packs." For CD gaps: "Use {spell_name} in {segment_name} — benchmark players cast it {benchmark_median} times vs your {player_casts}."

    - `_generate_boss_advice(gap: dict, boss_name: str) -> str`: Return string like "On {boss_name}, cast {spell_name} more — you had {player_count} casts vs benchmark {bench_count}."

    - `_build_dungeon_summary(seg_coaching: list[SegmentCoaching], death_coaching: list[CoachingItem], comparison_summary: dict) -> DungeonCoachingSummary`: Take flag counts from comparison_summary. Collect ALL non-positive coaching items across segments, sort by gap_pct desc, take top 5 as top_improvements. Build overall_coaching_text summarizing: "{N} damage issues, {M} CD issues, {K} deaths. Biggest area: {top_improvement}."

    - `coach_mplus_run(client, report_code, player_name, encounter_id, spec, key_level, fight="last") -> MplusCoachingResponse`: Call compare_mplus_run to get comparison data. Then iterate segment_comparisons calling _coach_trash_segment, boss_comparisons calling _coach_boss_segment, death_analysis calling _coach_deaths. Build summary. Return MplusCoachingResponse.
