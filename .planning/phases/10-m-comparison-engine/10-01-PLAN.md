    - _compute_gap(player_value, benchmark_value) returns dict with gap_pct and flagged boolean
  </behavior>
  <action>
    Create src/tools/mplus_comparison.py with module docstring following existing conventions (Chinese comments with ASCII block separators).

    Implement:
    1. _compute_gap(player_value: float, benchmark_value: float) -> dict:
       - If benchmark_value <= 0: return {"gap_pct": 0.0, "flagged": False}
       - gap_pct = round((benchmark_value - player_value) / benchmark_value * 100, 1)
       - flagged = gap_pct > 20.0
       - Return {"gap_pct": gap_pct, "flagged": flagged}

    2. _compare_trash_damage(player_damage: list[SegmentDamageBreakdown], bench_damage: list[SegmentDamageBreakdown]) -> list[SegmentDamageGap]:
       - Build bench_by_id = {d.spell_id: d for d in bench_damage}
       - For each player spell: find matching benchmark spell by spell_id
       - Compute gap_pct between player_pct and benchmark_pct: gap_pct = round(bench.damage_pct - player.damage_pct, 1), flagged = gap_pct > 20.0
       - For spells only in benchmark (not in player): add with player_pct=0.0, flagged=True if bench_pct > 5.0
       - Return list[SegmentDamageGap]

    3. _compare_interrupts(player_count: int, player_targets: set[int], bench_count_median: float, bench_targets: set[int]) -> dict:
       - count_gap = _compute_gap(player_count, bench_count_median)
       - critical_missed = bench_targets - player_targets (spell IDs benchmark interrupts but player doesn't)
       - Return {"player_count": player_count, "benchmark_median": bench_count_median, "count_gap_pct": count_gap["gap_pct"], "count_flagged": count_gap["flagged"], "critical_missed_target_ids": sorted(critical_missed)}

    Imports: from src.models import SegmentDamageGap, SegmentDamageBreakdown
