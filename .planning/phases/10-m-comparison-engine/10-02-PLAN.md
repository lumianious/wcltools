    Add to src/tools/mplus_comparison.py:

    1. _compare_boss_casts(player_spell_counts: dict[int, int], player_spell_names: dict[int, str], player_duration: float, bench_spell_stats: list[dict], kill: bool = True) -> BossCastComparison:
       - For each bench spell: find player count by spell_id, compute gap using _compute_gap
       - Build cast_gaps list: [{spell_name, spell_id, player_casts, benchmark_casts, cpm_player, cpm_benchmark, gap_pct, flagged}]
       - Status: "complete" if kill else "incomplete"
       - Return BossCastComparison with cast_gaps, status

    2. _compare_boss_cds(player_spell_counts: dict[int, int], player_spell_names: dict[int, str], tracked: dict[int, dict]) -> list[dict]:
       - For each tracked spell with ability_type in ("offensive_1min", "offensive_2min", "offensive_3min"):
         Check player casts vs expected casts (fight_duration / cd_seconds). Return cd_gaps list.

    3. _check_defensive_availability(death_ts: int, cast_events: list[dict], tracked_spells: dict[int, dict], segment_start: int = 0) -> list[dict]:
       - For each tracked spell with ability_type in ("defensive", "raid_cd"):
         - Find last cast of this spell before death_ts
         - If never cast: status = "available_never_used"
         - If last_cast_ts + cd_ms > death_ts: status = "on_cooldown"
         - Else: status = "available_off_cooldown"
       - Return list of {spell_name, spell_id, status, last_cast_sec}

    4. _build_death_breakdown(death_event: dict, damage_taken_events: list[dict], cast_events: list[dict], tracked_spells: dict[int, dict], segment_position: int, segment_name: str, run_start_time: int) -> DeathBreakdown:

       - defensive_status: call _check_defensive_availability
       - Return DeathBreakdown with death_time_sec relative to run start
