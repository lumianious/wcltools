  <files>src/tools/mplus_comparison.py, tests/test_mplus_comparison.py</files>

  <action>
    Add to src/tools/mplus_comparison.py:

    1. _align_segments(player_segs: list[dict], bench_segs: list[MplusBenchmarkSegment]) -> list[tuple]:
       - bench_by_pos = {s.position: s for s in bench_segs}
       - For each player segment: yield (player_seg, bench_by_pos.get(player_seg["position"]))
       - This handles mismatched segment counts gracefully (per Pitfall 1)

    2. async def _extract_player_segment_data(client, report_code, segment, source_id, tracked) -> dict:
       - For trash segments: query damage table, cast events, interrupt events using existing _query_segment_* functions from mplus_benchmarks
       - Extract: damage_breakdown via _extract_segment_damage, cds via _extract_segment_cds, interrupt_count via _count_segment_interrupts, interrupt_target_ids from raw events
       - For boss segments: query cast events, extract spell_counts and spell_names for _compare_boss_casts
       - Return dict with extracted data + segment metadata

    3. _build_segment_comparison(player_data: dict, bench_seg: MplusBenchmarkSegment | None) -> SegmentComparison:
       - If bench_seg is None: return SegmentComparison with status="no_benchmark"
       - Call _compare_trash_damage for damage_gaps
       - Build cd_gaps from player CD data vs benchmark cd_casts
       - Call _compare_interrupts for interrupt_comparison
       - Return SegmentComparison with all gaps

    4. async def _analyze_player_deaths(client, report_code, run_start, run_end, source_id, tracked, segments, max_deaths=5) -> list[DeathBreakdown]:
       - Call _query_death_events for death timestamps
       - Cap at max_deaths (per Pitfall 5)
       - For each death: determine which segment it falls in, query DamageTaken events in 15s window before death via _query_damage_taken_events, query cast events for full run, call _build_death_breakdown
       - Return list[DeathBreakdown]

    5. _build_summary(segment_comparisons, boss_comparisons, death_analysis, interrupt_summary) -> dict:
       - Count total flagged damage gaps, flagged CD gaps, total deaths
       - Identify top 3 segments with most flags
       - Return {"total_damage_flags": N, "total_cd_flags": N, "total_deaths": N, "total_interrupt_flags": N, "worst_segments": [...]}

    6. async def compare_mplus_run(client, report_code: str, player_name: str, encounter_id: int, spec: str, key_level: int, fight: str = "last") -> MplusComparisonResponse:
       Pipeline per CONTEXT.md locked decisions:
       a. Get player's dungeon data: _query_all_fights -> _group_fights_by_dungeon -> _select_dungeon_run
       b. Get benchmark data: await get_mplus_benchmarks(client, spec, encounter_id, key_level)
       c. Get source_id: find_actor_id_ci(client, report_code, first_fight_id, player_name)
       d. Build tracked spells: _build_tracked_spells(spec)
       e. Build player segments: _build_segment_positions(run_fights, boss_names)
       f. Extract player data per segment: loop _extract_player_segment_data
       g. Align and compare: _align_segments, _build_segment_comparison for trash, _compare_boss_casts for bosses
       h. Death analysis: _analyze_player_deaths
       i. Build interrupt_summary: aggregate across all segments
       j. Build summary: _build_summary
       k. Return MplusComparisonResponse with all data

       Parameters exactly per CONTEXT.md: report_code, player_name, encounter_id, spec, key_level, fight="last"
       Response per CONTEXT.md: segment_comparisons[] + boss_comparisons[] + death_analysis + summary
       Include benchmark values inline per CONTEXT.md: player_value, benchmark_value, gap_pct

    Add test to tests/test_mplus_comparison.py:
    - class TestCompareOrchestrator:
      - test_align_segments_matching: 3 player segments, 3 bench segments with matching positions, all align
      - test_align_segments_mismatch: Player has 4 segments, bench has 3, extra player segment gets None benchmark
      - test_build_summary_counts_flags: Given segment comparisons with known flag counts, verify summary totals
      - test_segment_comparison_no_benchmark: Player segment with no matching benchmark gets status="no_benchmark"
